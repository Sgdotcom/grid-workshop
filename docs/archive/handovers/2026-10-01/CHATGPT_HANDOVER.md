## 2. Core Architecture of Shape Welding

### A. The 3 Join Engine Modes (`src/lib/shapeJoinRegistry.ts`)
The workshop supports three runtime engines controlled via `getJoinEngineMode()`:
1. **`'main'` (Default):** Dispatches per-shape optimal joins. Circles and Rings are permanently locked to metaball welding (`isShapeLockedMetaball`). Other shapes use their custom tuned method (e.g. `weld`, `metaball`, `offset`, or `current`).
2. **`'fork-weld'`:** Pure Method B (`organicWeld`) across all shapes without shape-specific exceptions.
3. **`'fork-current'`:** Legacy Method A (`legacyJoinPreset` / `contactNeck`) without organic contour welding.

### B. Key Files & Line Number Breakdown
- **`src/lib/softness.ts`:**
  - `organicWeld(a, b, softness, site?)` — **Lines 766–955**: Main Method B outline weld. Walks stamp rings, identifies closest contact points, computes attachment chords and normal frame `(nx, ny)`, solves a 1D binary search for target waist thickness, builds cubic bezier flanks, and returns the closed weld polygon.
  - `WELD_TUNING` — **Lines 741–758**: Hyperparameters controlling outline arc fraction (`arcBase: 0.3, arcSoft: 0.25`), cubic handle length (`handle: 0.5`), waist pinch (`pinch: 0.75`), and minimum waist target (`waistBase: 0.34, waistSoft: 0.18, waistThin: 0.38`).
  - `arcPair` specialized flank solver — **Lines 864–884**: Custom cubic bezier waist generator for arc pairs that avoids the default binary search and preserves outline tangents with a shared central tangent.
  - `contactNeck(a, b, softness, diagonal, site?)` — **Lines 570–740**: Legacy Method A circular fillet bridge generator.
  - `joinSamePreset(preset, a, b, softness, gap, meanSize, safe)` — **Lines 1315–1348**: Dispatches same-shape neighbour pairs to their active join method.
  - `blendPairPolygons(a, b, softness, diagonal, safe)` — **Lines 1349–1396**: Dispatches arbitrary (mixed) shape pairs.
  - `fuseComponentPolygons(members, pairs, softness)` — **Lines 1450–1568**: Unions all stamps in a connected component with their pairwise weld polygons, followed by subtracting protected inner holes.
  - `softnessFinishPolygons(stamps, options)` — **Lines 1600–1690**: Full pipeline entry point. Clusters stamps into connected components, fuses each component, applies `HoleMode` filtering, and returns clean polygons.
- **`src/lib/shapes.ts`:**
  - `shapeOutlineRings(def, ox, oy, size, cornerRadius, rotation)` — Generates outer boundary and interior hole rings. Straight spans include midpoint samples (lines 130–170) to prevent corner-biased ray casting.
- **`src/lib/shapeJoinRegistry.ts`:**
  - `DEFAULT_SHAPE_METHODS`: Per-preset default method mappings (`weld`, `metaball`, `current`, `offset`).
  - `DEFAULT_DIRECTION_OVERRIDES`: Layout-specific overrides (e.g. square horizontal/vertical vs diagonal).
- **`src/lib/polyBool.ts`:**
  - `unionPolygons(polygons)`: Swept polygon union with 1000× integer grid snapping fallback if floating-point coincidence triggers clipping errors.
  - `filterPolygonHoles(polygons, mode, maxGapArea)`: Filters interstitial pinholes vs intentional counters.

## 4. Root Causes & Code Diagnoses for Known Bugs

### Bug 1: Input-Order Invariance Defect in `organicWeld`
- **Location:** `src/lib/softness.ts:775–835`
- **Symptom:** In 171 configurations, reversing the array order of stamps (`[A, B]` vs `[B, A]`) yields up to a 44.5% area delta (e.g. Circle at `(0,1)` and 4-star at `(1,0)`).
- **Code Breakdown:**
  1. `closestOutlinePoints(a, b)`: Ray casting order depends on which stamp is passed as first argument.
  2. `flanks`: `span(a0, b0) + span(a1, b1) <= span(a0, b1) + span(a1, b0)`.
  3. `ux = midB[0] - midA[0]`, `uy = midB[1] - midA[1]`: Normal vector `(nx, ny) = (-uy / ulen, ux / ulen)` negates when `a` and `b` swap.
  4. In `flank(p, q, sign)` (line 897): Tangent exit vectors `e.exit` are pulled toward `nx, ny`. Because `p` comes from `a` and `q` comes from `b`, the cubic binary search samples from `p` to `q`. If `a` and `b` are swapped, binary search numerical convergence evaluates in opposite directions, producing different `lo` values.
- **Solution:** Canonicalize the pair before welding:
  ```ts
  export function organicWeld(a: SoftStamp, b: SoftStamp, softness: number, site?: ContactSite): Polygon[] {
    // If not canonical order, swap and reverse result
    if (a.id > b.id && !site) {
      return organicWeld(b, a, softness)
    }
    // ...
  }
  ```

### Bug 2: Detached Island Slivers on Sharp Stars
- **Location:** `src/lib/softness.ts:949–953` & `fuseComponentPolygons:1550–1565`
- **Symptom:** `preset-star5` (size 56, softness 0.2, corners 0) in vertical layout produces 4 disconnected polygon components instead of 1 fused body.
- **Code Breakdown:**
  - At low softness (0.2), `arcFrac` is small (~0.35). The attachment point on a sharp star sits right next to a concave crotch.
  - The cubic flank intersects the concave star edge at an acute grazing angle.
  - After `toPolygon([simplifyRing(ring)])`, `polygonClipping.union(bodies, welds)` cuts off the sliver near the crotch, creating an isolated floating triangle island.
- **Solution:**
  - In `fuseComponentPolygons`, filter out any component whose area is smaller than `minComponentArea = meanSize * 0.05` if it does not contain a stamp center.
  - In `organicWeld`, ensure the bridge polygon clamps its anchor points outside concave crotches by checking the local boundary curvature.

### Bug 3: Triangle Pair Asymmetry
- **Location:** `src/lib/softness.ts:791–796`
- **Symptom:** Vertical pair of `preset-triangle` (size 56, softness 1, corners 2) has 0.88% axial asymmetry.
- **Code Breakdown:**
  - The mirrored contact site branch has:
    ```ts
    if (
      (dist(...posA.pt, ...reflectedA) > 1e-3 || dist(...posB.pt, ...reflectedB) > 1e-3) &&
      dist(...onA, ...reflectedA) < 1e-4 &&
      dist(...onB, ...reflectedB) < 1e-4
    )
    ```
  - For vertical triangles, `posA` sits directly on the axis of symmetry, so `dist(...posA.pt, ...reflectedA) === 0`.
  - The second point `posB` is off-axis, but because the outline of triangle `b` is discretely sampled in `shapes.ts`, `dist(...onB, ...reflectedB)` evaluates to `~0.0008` (which is `> 1e-4`).
  - As a result, the condition fails, the second mirrored site is rejected, and only one lopsided weld is produced!
- **Solution:**
  - Relax tolerance from `1e-4` to `Math.max(1e-3, meanSize * 0.002)` or project `reflectedB` onto the nearest segment rather than discrete sample points.

### Bug 4: Ring Hole Bleeding (Cutout Infill)
- **Location:** `src/lib/softness.ts:1391–1394` & `fuseComponentPolygons:1563–1566`
- **Symptom:** When a 56px solid shape is adjacent to a 24px ring, ~5.3px² of weld ink bleeds into the left edge of the ring's interior hole.
- **Code Breakdown:**
  - `contactNeck` does not subtract holes from its output; it relies on `blendPairPolygons` doing `differencePolygons(out, holes)`.
  - However, in `fuseComponentPolygons`, all pairwise pieces are unioned first (`unionPolygons([stampsOnly, ...pieces])`), and hole subtraction happens at the very end. If a bridge passes through the hole, `unionPolygons` merges it into a single solid outer contour, changing the topology before the final difference.
- **Solution:**
  - Explicitly subtract all interior rings (`s.rings.slice(1)`) from each pairwise piece *before* unioning into `result`, AND subtract them again after final union.
